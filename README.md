# Global Layoff Analysis (2020–2026)

Project Overview:

This project focuses on analyzing global layoff trends using Python and Power BI.
The goal of this project is to understand workforce reduction patterns across companies, industries, funding stages, countries, and time periods.

The project includes:

* Data cleaning and preprocessing
* Missing value handling
* Feature engineering
* Exploratory data analysis (EDA)
* Interactive Power BI dashboard creation
* Business insight generation

Tools & Technologies Used:

* Python
* Pandas
* Matplotlib
* Seaborn
* Power BI
* DAX

Dataset Features:

The dataset contains information related to:

* Company
* Industry
* Country
* Total layoffs
* Percentage laid off
* Funding raised
* Company stage
* Date of layoffs

Data Cleaning & Preprocessing:

The following preprocessing steps were performed:

* Removed unnecessary columns
* Standardized categorical values
* Fixed inconsistent company names
* Converted date columns into datetime format
* Handled missing values using median and mode
* Cleaned text formatting issues
* Corrected industry classifications

Feature Engineering:

Several new features were created to improve analysis:

* Funding Level
* Company Stage Group
* Layoff Severity
* COVID Period
* Full Shutdown Indicator
* Month & Year Features
* Layoff Percentage

2. Trends

This page focuses on:

Key Findings:

1. Top companies contributed nearly **75% of the total layoffs**, showing that workforce reductions were highly concentrated among a small group of major companies.

2. The **retail, hardware, consumer, finance, and transportation sectors** experienced the highest layoffs, indicating strong business pressure across customer-driven and operationally intensive industries.

3. Companies with **higher funding levels experienced more layoffs** than low-funded companies, suggesting that aggressively scaled businesses underwent larger workforce restructuring.

4. Mature companies accounted for nearly **75% of total layoffs**, highlighting that even established organizations were significantly affected during economic uncertainty.

5. Around **75% of total layoffs occurred after COVID-19**, reflecting the long-term business impact of post-pandemic market changes.

6. The year **2023 witnessed the peak layoff period**, recording the highest workforce reductions across companies.

7. The **United States reported the highest layoffs globally**, significantly exceeding layoffs in other countries.


Conclusion:

This project demonstrates an end-to-end data analytics workflow including:

* Data cleaning
* Feature engineering
* Exploratory data analysis
* Dashboard storytelling
* Business insight generation

The analysis highlights how economic uncertainty, post-pandemic market changes, funding structures, and company maturity influenced workforce reductions globally.
